# Carte de Bretagne — retro map

A high-resolution map of Brittany drawn in the style of an 18th-century copperplate
engraving (after Rigobert Bonne, 1771), built from OpenStreetMap data and Terrarium
elevation tiles.

| | |
|---|---|
| **Projection** | equirectangular, cos-latitude x-scaling |
| **Bounds** | 46.85–49.05 °N, 5.25–0.95 °W |
| **Master size** | 24 000 × 18 333 px |

## The route

The drawn track is the real driving route, 3 391 km from Weimar via Paris to Brittany
and home again by way of Nantes, of which 1 073 km falls inside the map frame.

Map data © OpenStreetMap contributors (ODbL). Elevation: Terrarium / Mapzen.
